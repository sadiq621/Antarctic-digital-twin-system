# Antarctic Digital Twin Prototype — SIH PS 26060

A responsive white government/enterprise-style frontend prototype for demonstrating remote management of Indian Antarctic research stations.

## Features
- Maitri / Bharati station selector
- Environmental telemetry
- Energy and battery monitoring
- Infrastructure health
- Logistics and inventory
- Alerts and incident management
- Responsive mobile dashboard
- Simulated demo telemetry
- No backend required

## Run locally
Open `index.html` directly in a modern browser.

For a local server:
- Python: `python -m http.server 8000`
- Then open `http://localhost:8000`

## Deploy
This is a static website. Upload the folder to GitHub and import the repository into Vercel or Netlify.

## Important
All displayed sensor values are simulated demonstration data and are not connected to real government or Antarctic station systems.
